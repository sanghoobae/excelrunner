# 셀 러너 (Cell Runner)

엑셀 화면으로 위장한 웹페이지 안, 셀 5행 높이의 좁은 띠에서 진행되는 원버튼 러닝·점프 게임.

## 실행

빌드 과정 없이 `index.html`을 브라우저로 열면 바로 실행됩니다.

로컬 서버로 띄우려면:

```bash
python -m http.server 5180
```

## 조작

| 키 | 동작 |
|---|---|
| `Space` | 점프 (길게 누르면 높이 점프, 공중에서 한 번 더 누르면 2단 점프) |
| `Enter` | 보관 아이템 사용 (`Ctrl+Z`, `=MAX()`) |
| `Esc` | 보스 키: 즉시 일시정지하고 게임 흔적 숨기기 |

## 구성

- 스테이지: 월요일 ~ 금요일 + 무한야근(생존 모드)
- 업그레이드: 하단 `업그레이드` 시트에서 코인으로 구매
- 저장: 브라우저 `localStorage`

자세한 기획은 [PRD.md](PRD.md) 참고.
